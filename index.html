Enter each value as 1–2 hex digits. The first value is treated as the multiplier (02, 03 in forward MixColumns), so the steps break it into powers of x. The product is the same either way round.

04 66 81 E5

Type 8 hex digits, with or without spaces. Each output byte is one matrix row times the column: four GF(28) products XORed together. Open any product to see its full working.

Reduction rule used throughout: if a left shift pushes a 1 out of bit 7, XOR the result with 1B, because x8 = x4 + x3 + x + 1 in this field.
