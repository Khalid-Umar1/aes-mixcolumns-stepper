AES Stepper

Encrypt or decrypt a block with AES-128, AES-192 or AES-256 and follow every round. You can also run any single phase on its own: Key Expansion, SubBytes, ShiftRows, MixColumns or AddRoundKey, down to a single byte.

block 128 bits AES-128 10 rounds AES-192 12 rounds AES-256 14 rounds field GF(28), m(x) = x8 + x4 + x3 + x + 1
All input and output is hex. State bytes fill the 4×4 grid column by column, as in FIPS-197. Default values are the FIPS-197 examples, so you can compare every step with the standard.
